verified_userKairoSDK v0.1.0 — solo developer certificati

L'SDK ufficiale per creare app KairoOS.

Una libreria C++ facile e divertente per disegnare, suonare e costruire interfacce. Con il wrapper namespace kec (Kairo Easy Coding) inizi a creare in un minuto. L'SDK non è pubblico: lo ricevi via email solo dopo la certificazione.

terminalIl tuo primo programma in 6 righe

#include "KairoECC.h"

kec::Canvas c(320, 240);
c.clear(kec::White);
c.icon("heart", 100, 100, 32, kec::Red);   // disegna un cuore
c.save("cuore.bmp");

Tutto vive nel namespace kec: per comodità puoi anche scrivere using namespace kec; una volta e poi usare Canvas, White e Red senza prefisso. Compila con un semplice make: l'SDK è una dylib per macOS (Apple Silicon) scritta in C++17, con anche la C API completa (KairoSDK.h). Tutto gira sul software renderer: nessuna libreria esterna.
